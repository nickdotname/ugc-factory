# DESCRIPTION BANK — YouTube Shorts (campaign clubs_yt)
#
# Written for YouTube specifically:
#   - Every record carries an explicit "title:" line, kept at or under 40
#     characters. Shorts displays about 40 in-feed; the previous bank derived
#     titles from Instagram caption openers and all 18 of them were truncated
#     mid-word. Config uses title_strategy: require so a missing title fails
#     preflight rather than silently deriving a bad one.
#   - Titles are written for search. YouTube matches Shorts on title and topic
#     far more than Instagram matches on caption text, so the title leads with
#     the thing someone would actually type.
#   - No "comment and I'll DM you" CTA. Shorts has no DM mechanic, so the ask
#     is both unactionable and spam-shaped.
#
# NOTE: a line may not START with "#" — the parser treats that as a comment.
# Hashtags therefore trail a text line.
#
# Records are separated by a line of ---
