# DESCRIPTION BANK — the text each video is posted WITH.
#
# This is the Instagram caption box / TikTok caption / YouTube description.
# It is NEVER drawn onto the video. On-screen subtitles are baked into your
# source clips before they ever reach this pipeline; the renderer contains no
# text filters at all.
#
# FORMAT: one record per block, blocks separated by a BLANK LINE.
# A description may span multiple lines — only a blank line ends a record.
# Lines starting with # are ignored, so notes are fine.
#
# CHARACTER LIMITS (validated at preflight, not at publish time):
#
#   platform    description   separate title
#   instagram   2,200         none
#   tiktok      4,000         none
#   youtube     5,000         100 chars, REQUIRED
#
# Only YouTube has a separate title. For a YouTube campaign, start a record
# with a `title:` line — preflight fails without one:
#
#   title: A Short Punchy Title Under 100 Chars
#   The long description body goes here, and may
#   run across as many lines as you like.
#
# A `title:` line on an Instagram or TikTok campaign is simply ignored, so one
# bank can serve several campaigns.
#
# SIZING: a cooldown of N days at P posts/day needs N x P distinct descriptions
# to never repeat inside the window. Descriptions are the cheapest asset to add
# — they are just text — so grow this bank before anything else.
