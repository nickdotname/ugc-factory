# Music licences

SPEC §4.4 — every track must be royalty-free. Baked-in commercial tracks get
fingerprinted, muted, or taken down, and repeat hits damage account standing.

Approved sources: Pixabay Music, Uppbeat (free tier), YouTube Audio Library,
Epidemic Sound (paid).

**Upload this file alongside the tracks in the campaign's assets Release.** The
renderer warns for any track with no row here, and the weekly digest lists them.
The filename in the first column must match the uploaded filename exactly.
