# Where the data comes from

Everything drawn in these videos is real and taken fresh each morning by `studio/earthdata.py`.

| What | Source | Terms |
|---|---|---|
| Satellites (orbits) | [CelesTrak](https://celestrak.org) GP data, active satellites, propagated with SGP4 | free to use, credited on screen |
| Airliners (positions) | [ADSB.lol](https://adsb.lol) public API, by aircraft type | Open Database License 1.0: credited on screen ("ADSB.lol (ODbL)") |
| Earthquakes | [USGS](https://earthquake.usgs.gov) M2.5+ feed, past 30 days | US government work, public domain |
| Coastlines, land | [Natural Earth](https://www.naturalearthdata.com) 1:50m / 1:110m | public domain |

Not used: OpenSky Network and ADS-B Exchange (their live data is for non-commercial use only).
